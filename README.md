# Sample.Beef.Tetris

This project is a small Tetris implementation for learning Beef while keeping up with changes across Beef versions.

- [beef](https://www.beeflang.org/)

``` cmd
> beefbuild -version
BeefBuild 0.43.5
```

## Used

- Lib:
  - [raysan5/raylib](https://github.com/raysan5/raylib)
  - [Starpelly/raylib-beef](https://github.com/Starpelly/raylib-beef/)
